# Data Transformer (SQL Project)

**Data Transformer** is a beginner-friendly SQL project that focuses on data manipulation using real-world business tables.  
The project simulates a **Corporate Data Analysis System** and allows students to practice joins, subqueries, date and string manipulation functions, window functions and SQL CASE expression.

---

## 📌 Tables Included

| Table Name   | Description                           |
|--------------|----------------------------------------|
| Customers    | Stores customer information            |
| Orders       | Stores customer orders with date/amount|
| Employees    | Stores employee details                |

---

## 💡 Tasks Covered

- INNER / LEFT / RIGHT / FULL JOIN
- Subqueries
- Date & String Functions
- Window Functions
- SQL CASE Expression

---

## 🚀 How to Run

1. Open MySQL CLI / MySQL Workbench.
2. Create a database and use it (e.g., `CREATE DATABASE data_transformer; USE data_transformer;`)
3. Create the 3 tables and insert the sample data.
4. Copy and run the SQL queries (provided in *data_transformer_queries.txt*).
5. Observe the results of each query to complete the assignment.

---

✅ The SQL queries are kept in a separate **data_transformer_queries.txt** file  
✅ You can upload both files directly to your Git repository
